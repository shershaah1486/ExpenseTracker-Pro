# 📖 About

Expense Tracker Pro is a responsive finance management web application that allows users to manage income and expenses efficiently. It provides visual analytics using pie charts, supports PDF and CSV export, and securely stores data using Local Storage.

---

# ✨ Features

- 💰 Add Income
- 💸 Add Expense
- ✏️ Edit Transactions
- 🗑 Delete Transactions
- 🔍 Search Transactions
- 📊 Pie Chart Analytics
- 📄 Export PDF
- 📑 Export Excel (CSV)
- 🌙 Dark Mode
- 💾 Local Storage
- 📱 Responsive Design

---

# 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Chart.js
